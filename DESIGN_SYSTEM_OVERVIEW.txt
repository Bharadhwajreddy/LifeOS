================================================================================
                         INTERACTION STATES
================================================================================

DEFAULT STATE:
  - Normal colors, no effects
  - Ready for interaction

HOVER STATE:
  - Background lightens slightly
  - Shadow increases (hover:shadow-md)
  - Y coordinate rises (whileHover={{ y: -2 }})
  - Duration: 200ms easeOut

ACTIVE/PRESS STATE:
  - Scale reduces (scale: 0.98 or 0.95)
  - No bg change needed
  - Quick feedback (100ms)
  - Haptic if available (mobile)

DONE/COMPLETED STATE:
  - Strikethrough text
  - Color fades (text-zinc-400)
  - Opacity drops (~60%)
  - Indicates "archived" state

OVERDUE/ERROR STATE:
  - Red text color
  - Red border highlight
  - Pulse animation (optional)
  - Draws attention to action needed

SELECTED/ACTIVE TAB STATE:
  - Blue background tint
  - White/blue text
  - Shadow/glow effect
  - Bold font weight

================================================================================
                         DARK MODE DETAILS
================================================================================

Implementation: Tailwind 'dark:' prefix + Zustand store

Toggle Flow:
  1. User clicks dark mode in Settings.jsx
  2. Store updates darkMode boolean
  3. App.jsx applies 'dark' class to <html>
  4. Tailwind applies dark: styles
  5. Persists to localStorage (Zustand)

Color Mapping:
  All colors have dark: equivalent
  Use custom values in [] for non-standard colors
  Example: dark:bg-[#161B27]

Contrast Requirements:
  Text vs Background: WCAG AA minimum
  Dark text on light: OK
  Light text on dark: OK with care
  Avoid low-contrast combos

Inner Glow (Optional):
  Dark mode cards can have subtle inset highlight
  Effect: inset 0 1px 0 0 rgba(255,255,255,0.1)
  Creates depth without harsh borders

================================================================================
                         COMMON QUESTIONS
================================================================================

Q: Where do I start?
A: Read DESIGN_README.md first, then follow IMPLEMENTATION_CHECKLIST.md Phase 1.

Q: Do I need to install anything new?
A: No. Tailwind, Framer Motion, and Lucide React are already in package.json.

Q: How do I implement dark mode?
A: Add dark: prefix to all color classes. Toggle via Settings.jsx store.

Q: Why square checkboxes?
A: Modern aesthetic. Matches Things 3. More premium than rounded.

Q: How long will this take?
A: ~11 hours for complete redesign. Can be done incrementally (Phase 1 = 1hr).

Q: Can I customize colors?
A: Yes. Edit TAILWIND_CONFIG.js or CSS variables in index.css.

Q: Will this affect performance?
A: No. Uses GPU-accelerated animations (transform). No layout shifts.

Q: How do I test dark mode?
A: Toggle in Settings.jsx. Adjusts darkMode in Zustand store.

Q: Are there components I can copy?
A: Yes. COMPONENT_EXAMPLES.jsx has 8 production-ready components.
