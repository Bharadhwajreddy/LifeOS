COLOR SYSTEM:

DARK MODE (Primary):
  Background:     #0B0F14 (deep navy)
  Cards:          #161B27 (dark gray)
  Text:           #F8FAFC (off-white)
  Primary:        #2563EB (blue-600)
  Secondary:      #14B8A6 (teal)
  Tertiary:       #8B5CF6 (purple)

LIGHT MODE:
  Background:     #F8F9FA (zinc-50)
  Cards:          #FFFFFF (white)
  Text:           #0F172A (slate-950)
  Primary:        #3B82F6 (blue-500)

PRIORITY INDICATORS:
  High:           #EF4444 (red)
  Medium:         #F59E0B (amber)
  Low:            #10B981 (green)

TYPOGRAPHY:

Page Title:       26px bold (700) - "Home, Alex 👋"
Section Header:   18px semibold (600) - "Today's Overview"
Body Text:        14px regular (400) - Task names, descriptions
Label/Caption:    11px bold (600) uppercase - "HIGH PRIORITY"
Font:             System default (SF Pro / Segoe UI)

COMPONENTS:

7 Core Components (with specifications):
  1. TaskItem          - Daily task with checkbox + priority
  2. AppointmentCard   - Event with time/location icons
  3. HabitRow          - Habit tracker with progress ring
  4. StatCard          - Finance metrics with change indicator
  5. PillTab           - Filter/navigation button
  6. FAB               - Floating action button (56x56px blue)
  7. CalendarDayCell   - Calendar grid cell with event dots

Plus 1 Utility:
  8. ProgressRing      - SVG circular progress indicator

ANIMATIONS:

Page Transition:    180ms easeOut - fade in + slide up
Checkbox Toggle:    300ms easeOut - scale bounce
Card Hover:         200ms easeOut - Y lift + shadow
FAB Press:          100ms easeOut - scale down
Progress Ring:      500ms easeOut - stroke animate
List Entrance:      200ms easeOut - fade + slide in

INTERACTION STATES:

Default:    Base colors, ready for input
Hover:      Lighter background, shadow, Y lift
Active:     Scale 0.98 or 0.95, quick feedback
Done:       Strikethrough, faded color, archived look
Overdue:    Red text/border, draws attention
Selected:   Blue tint, white text, shadow effect

================================================================================
                         KEY IMPLEMENTATION TIPS
================================================================================

COLOR IMPLEMENTATION:
  1. Add dark: classes to all color properties
  2. Use custom values in [] for non-standard colors
  3. Example: dark:bg-[#161B27] (dark card)
  4. Test dark mode toggle in Settings.jsx

COMPONENT STYLING:
  1. Square checkboxes: rounded-none (not rounded)
  2. Cards: border + border-color together
  3. Hover effects: Use dark:hover:bg-[#1F2433]
  4. FAB: Must be w-14 h-14 (exactly 56px)

ANIMATIONS:
  1. Wrap with motion.div for layout animations
  2. Use whileTap/whileHover for interactions
  3. Keep durations short (100-500ms)
  4. Test on slower devices

DARK MODE:
  1. All colors need dark: equivalent
  2. Toggle via Settings.jsx store
  3. Check text contrast (WCAG AA minimum)
  4. Verify borders are visible in both modes

TESTING:
  1. Test on iPhone SE (375px minimum)
  2. Toggle dark mode throughout
  3. Check touch targets (min 44px)
  4. Verify 60fps animations
